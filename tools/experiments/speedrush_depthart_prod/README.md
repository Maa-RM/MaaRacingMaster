## 背景与证据（上一轮对比结论，证据指针 = commit）

- 候选收敛：DepthART（10.6ms 全链、稳定、结构团块化）/ ZipDepth（23.6ms、结构最好、
  乱跳垫底）/ MoGe 生产 q4f16（56ms、质量基准、形态参考）。证据 = commit `592cefe`。
- DepthART 取舍：原生只出深度图（无 mask/points/normal/scale）；metric 档需内参
  且纯 ORT 跑不了；448×448 方形 0.2MP；slim-SPF 档 24.2MB / 5.91ms，结构三档最好。
- 生产集成面：缝只有 `depth_geo.infer_points`（MoGe 前向+reconstruct → pts/valid/diag）；
  module 层全部消费者（视角守卫 cam_h=coef[2]、边缘检测 sides/left/right、far_extents、
  _box_anchor_z）只吃该产物；normal 无人吃。重构 = 大块删除 MoGe 分支换 DepthART 分支。
- 规则拍板（2026-11-11）：保险杠机位 FOV 由相机配置给出——基准 64°、随速曲线
  56.9°→70.8°，正常速域折合 `fy≈613~664`，**取中间值 630 固定套用**（RULES §3.8
  已改）。固定值方案下焦距不必逐帧自估。

### 预处理必须按官方口径

官方链路：RGB/255 → ImageNet 均值方差 → `INTER_CUBIC` 拉伸到 448² → 输出 bilinear
`align_corners` 回原尺寸。ONNX 首节点是 Conv、图内没有归一化常量，网络吃的是**已归一化**
输入。194 帧近场带（行 430~670）上，slim 用官方归一化的地面残差 0.0042，用裸 `/255`
是 0.0067——上一轮对比的「/255 与 ImageNet 自选」实际总选 `/255`，其绝对校准数字与
本轮不可直接比。

### 变体：只有 slim 与 S 可跑

| 变体 | 输出方向 | 地面残差（归一） | 全链 p50 | 判读 |
|---|---|---|---|---|
| MNV4-S | 近=大（视差向） | 0.0063 | 5.8ms | 结构保留较好，备选 |
| MNV4-M | 近=小（深度向） | 0.0738 | 8.4ms | **退化**（旧轮结论成立） |
| MNV4-M-slim-SPF | 近=大（视差向） | **0.0047** | 5.8~10.9ms | **首选** |
| MNV4-B / metric 两档 | — | — | — | 自定义算子，纯 ORT 不可跑 |

- 相对输出是 **affine-invariant 视差向**：地面在模型空间是 `V = A + m·(r−y_h) + a·u`，
  米制换算必须走 `z = m·k/(V−A−a·u)`（`k = fy·cam_h`）。上一轮的 `z = a·V + b` 线性近似
  只在窄深度带成立，远场会发散。
- 水平分块（官方 KITTI tiled 口径）在 1280×720 上拼接后出现块间仿射不一致与接缝假近，
  地面残差反而从 0.005 升到 0.010；整幅拉伸更稳。

### 车道线独立几何：可以不要深度算相机高

逐帧用车道线交点估灭点行 `y_v`，再用 `cam_h = lane_w·(y−y_v)/Δx`（**不需要焦距**）：

- 与生产同步（2026-11-11，commit `cebfa34`：行扫描步长 3→1、提取不吃颜色）后：
  194 帧中 189 帧可算（原 174）；`cam_h` 中位 **1.271m**（原 1.254，权威 1.25），
  `y_v` 中位 361.3（原 361.6）；落视角守卫带的段占 80%（原 71%）。
- 步长 1 后远场虚线碎片变多，两两交点会给出 300~348 行的假灭点（撞车段 0102/0103
  实测）。灭点行改为三级门：**俯仰物理门 341~381（约 ±2°）+ 行 520 处线距 60~900px
  + MAD 剔除**；加门后分布与旧逻辑一致（p25~p75 354.9~362.2）。
- 相机高的半值尾巴（0.63）随步长加密消失（p10 从 0.63 升到 0.98），但 p90 仍到 1.42；
  越界帧需「≥3 条线 / 多对一致」置信门，缺证据时保持当前视角，不盲切。
- 有一段段中位 1.605（高于守卫带上沿）——线几何具备区分追尾机位的能力，待追尾样帧复核。

### 弯道、侧视与近距：几何的适用边界（`probe_curve_horizon.py` / `probe_contact_chain.py`）

- **弯道/偏航不影响行测距**：框底行公式只依赖俯仰（地平线行），与偏航无关。576 帧抽样、
  501 帧可算，按自车道曲率分桶（<0.5% / 0.5~1.5% / >1.5%），地平线中位 362.3/362.1/361.1，
  三桶 p10~p90 都落在 356~364；曲率与地平线偏差相关系数 −0.12。弯道本身不是风险。
- **真正的风险是俯仰/坡度/横坡**：地平线 1px 约等于 20m 处 2.5%、40m 处 5%、66m 处 8.4%。
  全池固定 361.3 的 p10~p90 是 355.5~364.3（std 3.8px）——**跨段/换赛道要重新标定**；
  出租车段内 IQR ~3px，40m 处约 ±8%。
- **侧视近车**：历史池 208 个最大车框按横向位置分「正前 / 邻道」。正前框的深度接触修正
  中位 2.6px、近场 <1px——框底就是接地点；邻道框的修正中位 3~6px、p90 140~157px，深度
  条带采到的是旁车侧面而不是地面。**邻道框的框底行给的是「最近侧面点」，不是纵向车距**，
  必须用横向门（|x|>1.2m 或框横向截断）分出去，否则会把 3~5m 的并行车当成「前车 3~5m」。
- 撞车段 0103（框 199×182、读数 7.3m）横向位置 2.63m，是邻道车而不是前车；此前把它当
  前车距离比较，属于指标错位。
- **深度的接触修正不上生产**：正前近场修正 <1px（可忽略），远场修正 −3~−6px 来自地面模型
  外推偏差，用了反而把中位误差从 12.9% 拉到 19%。深度只留作接触质量诊断（|修正|>10px 报警）。
- **几何的真实精度**：近场（10~20m）与框高一致 5~7%；40m 约 10~15%；66m 约 15~20%
  （地平线 ±2px + 框底量化）。这不是 2% 的银弹，但稳定、单调，误差来源只有地平线与框边。

### 偏移 A 压不下去（`probe_offset_filter.py`）

- 车道约束掩码 + 固定比例 + 3 帧中位：中位误差 20.6%（全带基准 11.4%），p90 从 83.2%
  降到 38.0%，跳变中位从 10.0m 降到 7.2m。**中位误差没进 10%，但尾部收窄了。**
- 车道约束掩码 + 对象框邻域局部行带参照（框下 −26/+18 行）：只剩 7 帧可解，中位误差
  290%。近地平线的路面行上 `V≈A`、比例项近零，局部 A 不可辨识——此路否掉。
- **同一探针在不同地平线/车道口径下重跑，结果不收敛**：全带基准在 11%~26% 间跳、掩码
  在 21%~29%、平滑在 20%~29%。这不是「再调一个窗口」能修的，是信号本身到了分辨率与
  偏移抖动的同量级。
- **中位数不是决策要的量**：全带基准中位 11.4% 看似可用，但 p90 83%、帧间跳变 10m；
  框底行几何 12.9%、p90 24%、跳变 1.7m。尾部与连续性才是走廊/刹车的输入。
- 结论：逐帧偏移不是「估得不够准」，而是远场 `V−A` 本身只有 0.05~0.18，A 的 0.1 级
  抖动与信号同量级。**这条路到此为止**，不再调窗口/门限。

### 焦距口径（相机配置，取代三锚推定）

- 保险杠机位配置：基准 `fov=64`，`CustomSpeedBasedCurveFOV` 启用，曲线 `CameraCurve2`，
  控制点 `(−0.045, 56.911°)`、`(516.256, 70.847°)`；游戏代码把 `GetFOVAngle` 当竖轴用。
  16:9 下 `fy = 360/tan(FOV/2)`，按竖轴或水平轴解释同一数值结果相同。
- 曲线两端 56.9°/70.8° 折合 `fy=664/506`；固定参考车速 41（RULES §4.8）对应的速域
  给出 613~664，常见巡航速域约 599~664。**取 630 固定套用**，残余 ±5%。
- 旧的三个锚：FOV 竖轴 664、MoGe 自估 670.7、线角按「1 分=1.22m」折算 662；807.7 是
  「1 分=1m」口径的离群值，已排除。焦距不再依赖车速口径，1 分=1m / 1.22m 的争议
  对米制链路不再有影响。

### 一次校准能走多远

- **尺度 `m` 可以一次校准**：撞车段 15 帧的 `m` IQR 2.7%，干净段中位聚类在
  0.0150~0.0156——相对深度的比例是稳的。
- **偏移 `A` 不能一次校准**：同段 `A` 从 0.238 漂到 0.419，跨段中位从 0.067 到 0.596。
  `z = m·k/(V−A)`，`A` 差 0.1 就是 20~30% 的距离差。
- 三种校准方式对 MoGe 的中位误差（本次口径）：逐帧全拟合 11.9%、一次校准 21.0%、
  单条车道线单点锚 36.4%；上一口径是 24.5% / 20.0% / 44.7%。**排序会随地平线口径翻面**
  ——这正说明偏移项对参照极敏感，不适合承担米制。
- 结论：**尺度可以一次校准，偏移不能**；要绝对米制，每帧/每场景的地面参照仍省不掉。
  中间路线（滑动中位/带门限的地面拟合、局部行带参照）已实测，见「偏移 A 压不下去」——都不够。
  **相对模型不适合承担逐车米制**，这是选型层面的结论，不是调参问题。

### 对生产重构的含义

- **逐车米制距离不再由深度模型承担**：主路是「框底行 + 校准地平线 + 固定焦距 + 权威
  相机高」`z = fy·1.25/(y_bot − y_h)`，框高几何做第二证据核对。两路一致中位 7%。
- 米制骨架 = 车道线（`y_v`/`cam_h`）+ 固定投影焦距 + 权威 1.25m；这部分不需要 DepthART。
- **绝对道号仍需要深度路心**：24 帧抽样里黄线路缘 0 帧双侧可检（4 帧单侧），线只能给
  相对横位；生产 `lane_obs` 的道号本来就靠深度路心锚定。因此「线为主」不能把深度几何
  全删——保留一个**低频深度路心**（启动/重锁用），逐帧走廊由线承担，断线用线图/记忆 coast。
- DepthART 的职责收窄为：低频路心 + 近场自由空间/占用（自由空间 ≤27m、占用 ≤15m）
  + 断线找边兜底。**不再担任逐车距离**——远场 448² 分辨力不够，近场它给出的数与几何
  重复；自由空间边界是贴地等值线、自带约 1τ 内缩，不能当车距。地面拟合 MAD>0.06 的帧必须弃用。
  MoGe 的逐帧焦距/位移/米制尺度与模型本体可整块删，**但点云消费方（平面拟合、近箱找边、
  最近一致边界、质量门）保留**——用合成点图喂它，读数与 MoGe 点云对齐（见「合成点图」节）。
- 迁移面因此收窄为一处：把点云生产者从 MoGe 换成「车道线几何 + 相对深度」的合成，接缝
  `infer_points` 的返回契约不变。
- 逐车距离的换法直接替换 `_box_anchor_z` 的「框底条带深度中位」语义；该函数现在是
  MoGe 米制点云的消费者，改造后吃「框底行 + 地平线 + 焦距」。
- 未闭合：FOV 曲线横轴单位；地平线跨赛道标定的实现（标定值存哪、何时重标）；邻道门的
  横向参考要从相机轴改成自车道中心；框底/框高边缘噪声（阴影、遮挡、截断）的判别；深度
  路心的供数频率与失效门限；追尾样帧的守卫判别；>50m 远场策略。

### 自由空间与占用（`probe_freespace_chain.py`）

- 近场（行 405~690，约 2.5~27m）用「贴地判据」`|V−V_g| ≤ 0.05` 取自由空间。地面残差
  实测 p50 0.010~0.027、p90 0.025~0.055（绝对口径），故 τ=0.05，不是 0.005（那是归一化口径）。
- **车道线像素贴地率**：撞车段中位 90%（p10 77%），稳定段中位 89%。按地面拟合质量门
  （MAD ≤0.06）过滤后：撞车段 14/15、稳定段 33/40 可用，贴地率中位 92%、p10 80%。
- **自车道自由空间占比**：撞车段中位 95%，稳定段中位 91%；拟合门后稳定段中位 93%。
- **障碍**：只在 z 5~15m 扫，连续 4 个采样行自车道非地面 >0.5 判障。近前车 2 帧
  （框距中位 9.3m）自由空间降到 52%、障碍 48%，边界距离中位 7.0m（偏近、保守）。
  稳定段 33 个可用帧里 3 帧报障，假阳约 9%。
- **边界距离不能当车距**：边界是贴地判据的等值线，天生带 τ 的内缩；它只用于占位/走廊，
  距离仍由框底行几何给。具体量级见下节「边缘锐度归因」。
- **拟合门是必须的**：邻道大车贴脸时地面拟合 MAD 到 0.3~0.8，自由空间整体失效
  （0103：贴地率 11%、自车道 13%）。MAD>0.06 的帧必须弃用并回退到线/记忆。

### 左右边界对上生产 MoGe（`probe_corridor_sides.py`）

40 帧抽样、65 组左右可比对（车道单位，左负右正）：

| | MoGe 中位 | DepthART 中位 | 逐帧 \|差\| 中位 | p90 | 符号一致 |
|---|---|---|---|---|---|
| 左缘 | −2.46 | −1.50 | 0.27（约 0.9m） | 1.58 | 100% |
| 右缘 | 1.73 | 1.57 | 0.20（约 0.7m） | 0.93 | 100% |

- **方向是系统性的偏窄**：DepthART 两侧都更靠内，没有一帧比 MoGe 更宽。原因是判据不同——
  MoGe 找「地面→竖直结构」的离地穿越，会跨过路肩找到墙根/路缘底；DepthART 找「贴合拟合
  地面」，路面横坡、路肩变坡、标线与旁车都会让它提前收边。
- **覆盖比 MoGe 好**：40 帧里 MoGe 两侧齐 28、单侧 11、全无 1（平面拟合失败）；DepthART
  两侧齐 39（余 1 帧为贴脸大车）。连续供数上 DepthART 更稳。
- 差异最大的几帧集中在「左侧有旁车/路肩变坡」（贴脸大车那帧左侧收到 −0.09 车道）与
  「跨两条车道找墙」的对照帧；地面拟合 MAD>0.06 的帧本次 3/40，照旧弃用。
- **对走廊的含义**：偏窄在安全侧，不会把车引向墙；代价是可能压窄走廊导致多余减速。
  接入时给深度边界设下限（单侧不小于约 0.9 车道），并让车道线做主语、深度只做否决与
  兜底——与「逐车距离不用深度」一致。

### 合成点图喂生产消费方（`probe_synth_cloud.py`）

口径：逐像素判贴地；贴地像素的米制距离由**车道线几何**给（`fy·cam_h/(r−y_v)`，不经过
深度模型）；地面以上用相对深度 `m·k/(V−A−a·u)`；反投影时把主点行取灭点行，使平路
`Y ≡ cam_h`。点图直接喂生产 ``reading_from_points``（平面自拟合、近箱离地穿越、最近一致
边界、质量门全部原样），与同帧 MoGe 点云读数对照。

| | MoGe 中位 | 合成中位 | 逐帧 \|差\| 中位 | p90 | 符号一致 |
|---|---|---|---|---|---|
| 左缘 | −2.50 | −2.42 | 0.16（约 0.6m） | 0.53 | 100%（n=34） |
| 右缘 | 1.68 | 1.66 | 0.09（约 0.3m） | 0.38 | 100%（n=31） |

- **比直接拿自由空间掩码量边界更接近生产**：那条路是左 0.27/1.58、右 0.20/0.93；合成点图
  走生产同一套找边逻辑后是 0.16/0.53、0.09/0.38。差异来自消费方找的是「离地穿越」，
  合成点图把近场竖直结构如实还原了。
- **自洽性交叉验证**：消费方从合成点图自拟合出的路面平面是 `a≈0`、`b≈0.0009`、
  `c=1.248`，与权威相机高 1.25 吻合——合成地面没有引入倾斜或缩放。
- **覆盖**：40 帧里合成 31 帧双侧、8 单侧、1 全无；MoGe 为 28/11/1（全无那帧是平面拟合
  失败）。单侧的成因与 MoGe 的「无穿越」同性质（近箱没有竖直结构）。
- **唯一被质量门拒绝的帧是贴脸大车**：地面拟合 MAD 0.19、贴地率 19%，走的正是预定的降级
  路径；它同时是 MoGe 报「平面拟合失败」的同一帧。
- 结论：**迁移可以只换生产者**。消费方的平面拟合、近箱找边、最近一致边界、质量门全部
  原样复用，不需要重写成「车道线 + 深度」的第二套逻辑。

### 地平线来源（`probe_horizon_sources.py`）

- **可辨识性**：扫 `y_h` 340~390 重拟合地面模型，5 帧的残差 / MAD / m **逐位不变**
  ——相对深度是视差向仿射不变量，`y_h` 与偏移项 A 共线，**深度本身给不出地平线**。
- **来源对比**（40 帧，以车道逐帧灭点行为基准，合成点图喂生产消费方）：
  gate0 固定 354.2 左缘差 p50 0.173 / p90 0.34 车道、右 0.079 / 0.149；
  固定 361.0 左 0.064 / 0.164、右 0.027 / 0.077；平面自拟合 c 差 ≤0.01m。
  车道逐帧 `y_v` 中位 361.27（p25~p75 358.5~362.2）。
- **半幅点图**（每 2 像素取 1，ds=2）与全幅读数差：左 p50 0.001 / p90 0.006、
  右 0 / 0.004，c 差 ≤0.0009 → 生产按半幅 360×640 生成安全。
- 结论：地平线用车道线逐帧灭点行（车道模型本就在跑，零新增推理），缺值回退
  gate0 `y_h`；不新增固定常数。

**并发排布实测（`concurrency_check.py`，20Hz 拍 + 深度异步 + 线观测，10 秒）**

| 线编排 | 控制拍 | 线成功 / 弃帧 | 深度新结果 / 弃帧 | 深度龄 p50 / p95 |
|---|---|---|---|---|
| CPU（生产现状） | 193（19.3Hz） | 201 / 0（20Hz） | 94（9.4Hz）/ 0 | 54 / 143ms |
| DML（抢锁） | 196（19.6Hz） | 182 / 19（18.2Hz） | 90（9Hz）/ 6 | 52 / 112ms |

- 深度节流窗扫描（线 CPU）：100ms → 6.4Hz（龄 p50 103ms）；80ms → 9.2Hz；70ms
  → 9.1Hz；60ms → **9.4Hz、龄 p50 53ms**。选 60ms 是因为错峰平均吃掉约 25ms；
  100ms 窗的实际频率远低于名义 10Hz。
- 线走 CPU 是既有实机决定（DML 与深度同锁会互相挤）；同机对比显示换 DML 并没有提高
  任何一方的新鲜度，反而让线与深度的成功率同时下降（线的单次耗时 35→6ms，但三方
  共享一把锁后成功率从 100% 掉到 90%）。
- 最小抢锁编排 = 线 CPU（不碰 DML 锁）+ 感知阻塞持锁 + 深度错峰非阻塞。CPU 模式下
  深度弃帧 0，结果龄 p50 53ms，196 拍里 193 拍有读数（其余复用）。
- **取消等拍的 A/B**（`--depth-wait none`，40ms 窗时代）：新结果 130→145 次
  （13→14.5Hz），但结果龄 p50 53→101ms、p95 125→195ms，弃帧 0→9。即「跑完就发」
  只多 11% 班次，装的是上一拍乘客；等拍是更好的权衡。


### 微基准（`micro_bench.py`）

同数据、同语义替换实现方式的耗时（ms，p50）：

| 热点 | 原实现 | 替代 |
|---|---|---|
| 448→720p 双线性 | 11.2（fp64）/ 10.4（fp32） | OpenCV remap **0.25~0.34** |
| 地面拟合（10 万点，4 轮 lstsq） | 15.6（整段 18.8） | 2.5 万点 3.9；正规方程 3.4 |
| 合成点图 | 8.1 | fp32 版 8.5（无改善→是运算量，不是 dtype） |
| 栅格 | 11.1 | — |

结论：慢的不是 Python 解释器，而是热点写法——720p 插值走了 Python 级四份
gather（两次下标 + 两次广播乘加），换成 C++ 原语后从 11ms 掉到 0.3ms；地面拟合
的 SVD 换成 3×3 正规方程、点数降 4 倍，18.8ms 降到 3.8ms。两项做完 `points`
段从 56ms 压到 12ms，深度全链落到 38ms。剩余大头是找边（17.5ms）与栅格（10ms）。


### 边缘锐度归因（`probe_boundary_blur.py`）

- ONNX 是 448² 进、448² 出、单输出，图内没有归一化常量，也没有可用的 mask/置信度分支；
  预处理（ImageNet 归一 + `INTER_CUBIC` 拉伸）与 bilinear 回原尺寸之外没有别的官方后处理
  可漏。
- 真实深度跳变（车顶对背景）在 448 网格上 10%→90% 只跨 2~3 行；车体内部 `V` 对行的斜率
  只有地面斜率的 −0.12~0.03——**模型给物体的是平坦深度，没有向地面渐变的涂抹**。
- 接触线（车胎接地）处 448 上跨 6~12 行、720 上跨 10~18 行，比几何预测高 3~5 倍。这是两件
  事叠加：① 接触处深度本来连续，`|V−V_g|` 由 0 升到 1.5τ 是一段斜坡，而 **τ=0.05 折成地面
  深度在 10m 处约 0.5m、25m 处约 1.5m**，所以「几米」这个量级由阈值本身决定；② 多出的
  4~9 个 448 行软化集中在小目标接触处（16m 车在 448 上只有约 39 行高），目标越小越明显。
- 结论：**「边界糊约 2 米」是度量口径错误**——把 τ 当成边缘宽度量在了深度连续处；不是模型
  全局模糊，也不是预处理/上采样漏步。可用口径：自由空间边界相对接触线保守内缩约 1τ。
- 论文 Figure 4 的 `VAR trained with DepthART` 是另一支大模型，不是本实验的 slim-SPF 检查点；
  论文自己的模型横向对比图里 slim-SPF 是六者中边缘最软的一档，同级开销里 TinyViM-S 明显
  更锐。若后续需要更锐的结构，换 TinyViM-S 是同量级代价的选项，链路不用改。

## 伪生产方案（本轮口径）

```
DepthART slim-SPF（官方预处理）
  → 近场自由空间/占用（≤27m / ≤15m，地面拟合 MAD≤0.06）+ 低频深度路心 + 断线找边
车道线
  → 地平线行（按赛道/机位标定，段内慢速中位）、cam_h、走廊中心
perception 框 + 横向位置
  → 横向门：|x|>1.2m 或框横向截断 = 邻道（给最近距离，不给纵向车距）
框底行 + 地平线 + 固定焦距
  → z = fy·1.25 / (y_bot − y_h)        ← 正前车距离
框高（在线估目标高）核对 → 两路分歧超限时降权/回退
MoGe q4f16 只作对照基线
```

**焦距方案**：固定 `fy=630`（相机配置曲线 613~664 的中间值），逐帧自估焦距（MoGe 降频
或深度图解算）只作对照。

## 验收五条（修订）

1. 逐车距离：框底行几何与框高几何两路一致中位 ≤10%、真接近段单调无回跳；与 MoGe
   基线的偏差只作观测，不作判据（MoGe 自身在近场偏 30%+、远场抖 20m）；
2. 正前/邻道分类：横向门在并行车、跨道车、框横向截断三类上有正反例，邻道不给纵向车距；
3. 相机高：车道线独立估计的段中位落 1.12~1.55，且能区分追尾机位；
4. 自由空间：车道线像素贴地率中位 ≥90%、自车道自由空间占比中位 ≥90%；地面拟合
   MAD≤0.06 的可用帧 ≥80%（实测 33/40）；
5. 全链延迟（预处理+推理+回原尺寸+结构提取）p50。
