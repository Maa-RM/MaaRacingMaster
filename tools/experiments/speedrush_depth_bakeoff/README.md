# speedrush_depth_bakeoff — 深度模型选型取证

> **本文是什么**：回答「深度模型为什么每轮离线验收都通过、上实机就不准」的三条独立取证
> ——历史选型会话原文、生产常量链、外部方法论。这三份材料是本轮唯一的新增产出。
> **本文不是什么**：不是尺度定标结论，不是参数真源（归 `resources/calibration/gate0.json`、
> `depth_geo.py`、域 `RULES.md`），也不是选型建议。**信源等级**：L4（过程与证据）。

## 已验证可复现的事实

- 同一画面同时存在两个焦距常数：纵向锚点用一个，线角用另一个，二者相差约 28%。
  生效值以 `depth_geo.py` 与 `gate0.json` 为准，本文不复制数值。
- 相机高可由车道线间距独立反解，且该反解与焦距无关；实机多帧中位数与配置值一致。
  所以「相机高错」不成立，「焦距/相机高乘积」才是未定项。
- 历史选型的验收指标是序与形状：近远序在十个模型上全部饱和到 1.000，平整度被障碍污染，
  没有任何一次用已知真值校验绝对距离。这类指标对全局尺度错误天然免疫。

## 未成立、不得引用为结论的部分

- 焦距真值。运动法给出的偏小候选存在三处缺陷：候选间可见点集合不同（焦距小时近处点出画）、
  取点未认证为静态地面、时序是采集回调到达时刻。复核已证明原打分受取样方式影响。
- 视角曲线与候选值「数值接近」不构成旁证：角度轴（横/纵）、曲线输入单位与运行时消费未闭合。
- 双焦距相差的百分比不是真值误差界；框高通道与框底通道的比值也不会因单改纵向焦距而收敛。
