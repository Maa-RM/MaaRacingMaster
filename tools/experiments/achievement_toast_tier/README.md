# achievement_toast_tier — 成就灵动岛形态原型

status: active

## 这个原型回答什么

成就解锁提示以「灵动岛」形态落在大窗口里是否成立：

- 三态切换（圆点入场 → 胶囊 → 详情卡）的变形节奏读不读得懂；
- 多条成就同时到达时的排队顺序与串行节奏，队列层次是否一眼可辨；
- 四档（普通 / 稀有 / 珍贵 / 隐藏）靠整条描边区分是否足够，白底黑字下会不会压制可读性；
- 岛落在大窗口中下部、水平居中时，会不会压住正文或抢走视线。

## 产物

`preview.html` —— 单文件、零依赖、直接浏览器打开。内含模拟窗口（顶栏 / 两列卡片 / 状态栏），
岛固定在窗口底部状态栏上方、水平居中。

## 当前形态

- **两态停留 + 形变过渡**：停留态只有「胶囊」（图标 + 标题 + 描述）与「详情卡」；圆只作为入场与退场的形态，不承担停留展示。
- **队列**：旧的在队首（最下方），新到的往上方排，间距 8px；队首满亮，候队轻微变淡。
- **串行推进**：队首展示满 5 秒即缩成圆点消失，后一条顶上并重新计时；某条处于详情态时暂停推进。
- **点击层级**：点胶囊展开为详情卡（320×156，含档位、解锁时间、触发条件），再点收回胶囊；点窗口空白处或静置 9 秒同样收回。
- **档位**：色彩落在整条外圈的中粗描边（2.5px）上，图标为中性墨色；隐藏档描边换成 OKLCH 全色相环缓慢旋转，标题走 `.maarm-text-scan--rave` 彩虹字。
- **副标题**只放描述，档位信息由描边与详情卡承担。

示例成就四条（普通 / 稀有 / 珍贵 / 隐藏各一），取自主控的真实可触发场景。
