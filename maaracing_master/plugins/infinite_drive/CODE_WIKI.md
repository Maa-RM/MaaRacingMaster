## 1. 施工状态

流程模块管理入口、关卡挑战、按条件选车、选卡、驾驶、结算与放弃重开。选卡按卡名优先级点槽，以商店关闭为完成信号。事件介绍页靠页面锚点关闭，奖励链等偶发提示走公共 OCR 文案白名单。

连刷轮数由配置面板的滚轮计数器选定（0 = 不限，默认不限）：一轮 = 关卡挑战到结算的完整循环，胜负都计入，刷满即正常收尾。面板说明文字里的预计用时取战绩库的轮均结算间隔（同一次运行内相邻两次结算的时间差中位数，`dashboard_store.median_round_seconds()` 是唯一入口），随每次结算落库重建表单声明刷新；无历史记录不下发估计值。任务卡标题栏摘要始终带连刷设置。

驾驶模式可选全程直行或自动驾驶，默认全程直行；全程直行档不显示录制人工语料开关。两档用计分条或倒计时齿轮确认驾驶画面，转场和采集超龄时归还手柄。驾驶画面持续离开后才查结束页与偶发弹窗，弹窗 OCR 由流程限频触发。

自动驾驶在每轮第一阶段首次出现驾驶画面时按一次切视角键，等镜头切换动画后持续检测。第二阶段沿用机位并直接检测。定位以黄线路缘为起点，在同一图像行按白线与路缘相隔的道宽数定道号。偏暗路缘须由两条白线共同复核。黄线缺测时沿用车道线锁定的道号与当帧测量，线锁丢失时继续检测并等新的路缘证据。车道稳定后，将同帧街车框的接地位置投影到道路横位和前向距离。横向维持六个擦边点位之一（三条白线两侧各偏 0.2 道：与相邻车道居中车的横向中心距 ≈2.45m，恰好落入极限超车判定阈 RULES §2.1），初始取离自车最近的净点；维持点被堵才换到最近的净点，净空恢复不切回。方向杆朝维持点做前视转向，用实测车头角和角速度回正。视界内六个点位全堵时收油，出现净点即恢复。无同拍街车观测时维持现点位，车道线证据不足时当拍方向归零。

自动驾驶档可开启录制人工语料：由玩家驾驶，整个流程的画面和物理手柄数据作为影子数据写入调试目录；全程直行档不保留录制开启态。战绩看板读取程序局结算，驾驶记录在日志会话中提供路缘定位、目标车道、车头角读数和输出转向的对应关系。

分数超本关目标后走提前结算省时（机制见 RULES.md §0.5）：驾驶中低频 OCR 比分（区域真源 ``pve_score``，右缘收在头像之前），连续超目标即松杆经设置页中途退出按当前分数结算。阶段2退出落地结算页即现有结束信号；阶段1退出跳过选卡2与阶段2直达结算步，与自然结束共用同一批后续步骤。退出序列任一步没落地先回赶（确认框取消 / 设置页继续）回到驾驶，触发自然重试；确认框被「今日不再提示」跳过时按结算页在位免点确认。

## 2. 真源分立

| 真源 | 住户 | 口径 |
|---|---|---|
| 游戏事实 | [RULES.md](./RULES.md) | 外部事实，人工复核制；只收 v2 核对未变条目 |

## 3. 模块索引（按职责分组）

## 4. 坑点（搬迁模块注释明确记载、与 v2 事实无冲突）

只收模块 docstring / 注释里明确记载的坑点，逐条附出处；拿不准的不收。v2 事实变化面（HUD 改版、环境换海岸等）对相关读数的影响按 RULES.md 收录口径走后续核对。

- **DML 锁与 GPU 排班**：线观测走 GPU 槽位排班——等控制拍放锁后的槽窗开跑，放锁即交还锁，超窗放弃本帧、不抢锁（[lane_obs.py](./lane_obs.py)）。DML 调用卡住时外部采样命令会被一起卡住，取证线程必须分开（[gpu_probe.py](./gpu_probe.py)）。
- **HUD 读数降级与敌我判定**：读不出的格只带原始文本与不可信标志，不静默丢、也不冒充读数；两块比分面板会上下互换，敌我按块色成对判，位置永不参与判定；两卡版式不同，身份先判、再按身份选题框——按槽位取一个「够大的框」会把对手比分末位读掉或把图标读进来（[hud.py](./hud.py)）。区域真源是 v1 标定，v2 HUD 改版后需重验（见 §2）。
- **归一纪律**：未经按行归一的像素横向差禁止当距离用——横向读数一律来自车道线拟合或经标定尺子归一，距离按框底行落差对地面投影换算；标定常数不写字面量默认值，全部从标定真源 fail-loud 读取（[world_model.py](./world_model.py)）。
- **XInput 槽位锁定**：虚拟手柄在程序不驱动时恒为静止全零，锁错槽位会把整局录成全零——文件看着完好，比没有数据更坏；两个录制器共用同一份挑选规则，不得各写一遍（[pad_source.py](./pad_source.py)）。
- **录制反压**：帧入队用非阻塞投递，队列满即丢帧并计数，绝不阻塞采集侧；叠加图渲染在落盘线程串行，失败只计数不抛（[recorder.py](./recorder.py)）。
- **道路定位依赖路缘和白线的同拍证据**。车道线缺测期间仍继续提交画面，线锁和车头角恢复后即可继续转向。相关门槛见 [驾驶控制](./driving.py)。
