# speedrush 目标正确性·基线口径

本文件说明「每个数在量什么」。可执行定义在 [`metrics.py`](metrics.py)（参数表 `PARAMS`），
结果由 [`recompute_report.py`](recompute_report.py) 从原始 trace 生成并落到
`RECOMPUTE_REPORT.md` / `.json`。三者关系固定为：

> `metrics.py` 定义 → `recompute_report.py` 计算 → `RECOMPUTE_REPORT.*` 出数 → 方案只引用报告

阈值不在本文件重复写，只引用参数名；报告里打印的是脚本实际使用的值。
口径版本见 `metrics.CALIBER_VERSION`，任何参数或剔除规则变化都必须升版本。

## 通用前提

| 项 | 规定 |
|---|---|
| 分段 | 按 `round + stage_id` 切段；段内相邻拍时间差超过 `seg_gap_s` 也断段 |
| 时间基 | 一律用 `ts_ns` 实算；间隔分布见复算报告 |
| 缺读 | 非有限值按缺读处理；缺读、已有重基标签与路线参考系纪元变化处断段，不插值、不前值填充；断段时长不进分母 |
| 坐标系 | 距离与横位单位「道」，`lane_w_m` 换算米；机会与自车必须同坐标系 |
| 分母 | 一律显式声明；不适用/未观测与前值保持分别计数，不并入分子分母 |

## 指标

### B. 反转率

- 测量对象：一条横位序列的变化方向，不涉及该序列是否代表车辆真实轨迹。
- 序列：`x_target`（下发目标）、`executed_lane`（程序内部横位估计）、`lane_obs.x`（视觉横位读数）。
- 统计量：**滞回反转**——反向累计位移达到 θ 才确认一次反转；θ 取 `rev_theta_sweep` 全部报出，不选单值。
- 分母：段内非 `None` 连续片段的真实时长之和。
- 剔除：缺读、已有重基标签和 `route.ep` 纪元变化处断段；跨段不比。未记录的来源重锚不猜测。
- 同向段长度记录的是滞回确认点之间的拍数，首尾按观测窗截断；汇总阈值取 `run_summary_theta`，不是实际运动周期。
- 适用范围：三条序列各自独立报告，**不做互相换算**，也不以其中任一条代表「真实轨迹」。
  `executed_lane` 的方向来源是模型预测（速度取固定参考车速、车模读入程序杆值），
  是程序内部状态，不是独立观测。

### C. 引用一致（车类动作）

- 测量对象：选择层动作所引用对象身份，在本拍场景/对象表中的存在性。
- 信号：`sel_dbg.hit_oid`（仅 graze/pass 非空）。
- 三态：在规划场景 / 仅在对象表 / 两边都无；「仅在对象表」再按 `safety_why` 分。
- 分母：有身份拍。全段拍数与被覆盖面单列。
- 适用范围：**只覆盖车类动作**。金币/奖励目标没有 `hit_oid`，另见 D。
- 报表不得把它写成全段目标正确率。

### D. 目标身份候选匹配

- 测量对象：本拍所选奖励/金币目标的对象身份。
- 信号：`sel_dbg.rw` / `sel_dbg.coin`（每项 `[x, t]`）与 `sel_dbg.src_elig.rw_sel` /
  `coin_sel`（每项 `[id, seen, src]`）是逐项同序平行表。
- 判据：与本拍 `sel_dbg.target` 相差 ≤ `identity_candidate_lane` 的候选中唯一命中记「唯一」，
  多于一个记「歧义」，零个记「无匹配」。这只是邻近候选筛选，唯一候选也不证明身份正确。
- 适用范围：需要 `eligibility_latch` 打开（否则无平行表）；金币的 x 会被夹边与组平滑改写，
  匹配规则以「唯一命中率」度量，不假设 100% 可还原。

### E. 几何分量对账

- 测量对象：连续两拍均入选的同一车身份，场景横位的**分量构成**，不是「对象是否跳变」。两拍都需存在场景和车源，不能外推到全部车对象。
- 恒等式：`scene.x = carsrc.xr − origin − cd + fshift`，残差即闭合误差。
- 分量：`Δxr`（对象横位，含自车位置估计的平移）/ `Δcd`（路心在目标深度的插值补偿）/
  `Δorigin` / `Δfshift`。
- 筛选：`geom_require_adjacent` / `geom_require_seen_both` / `geom_require_same_src` 三项同时成立，并排除已有重基标签或路线参考系纪元变化。来源相同只指场景发布标签相同，不证明底层测量锚点不变。
- 输出：符合筛选的目标对数、场景位移超过 `geometry_event_m` 的条数、闭合误差、幅度主导分量、四分组（仅 xr / 仅 cd / 两者 / 都未超）；闭合容差取 `closure_tolerance_m`。
- `xr` 超阈总数为「仅 xr + 两者」，主导项是幅度排序，不能当作根因归属。逐事件时间、帧号和有符号分量在 JSON 的 `event_details` 中。
- **不出判定**：阈值未标定。`Δcd` 的逐拍上限不是单个采样点的限拍步长
  （目标补偿是两点插值之差，两点可反向变化），因此不能由「接近 1.05 m」推断饱和。
- 适用范围：`xr` 含自车位置估计与滤波/保持，不是独立测得的车辆物理横移。

### F. 请求覆盖

- 测量对象：本道无机会、旁道有机会时，是否发起请求。
- 场景判据：`toa` 落在 `[toa_min_s, toa_max_s]`；「本道」按 `near_lane`。
- 两种分母**都报**：按拍（每拍独立）与按 episode（连续满足条件的拍合并为一段）。
- 适用范围：只用选择快照的同坐标自车位置；缺失时记未观测，并打断 episode。车类机会不在本项分母，人工局仅报告影子决策。

### G. 杆值

- 测量对象：杆幅占用与单次持杆时长。
- 标尺：`stick_deadzone_raw` 按 int16 绝对值，程序 `steer_x` 与人工 `pads.lx` 同一标尺。
- 统计量：零杆样本占比与时间占比分开，持杆时长中位与均值同时给；名义频率、实测频率、缺口与截断边界均入报告。
- 时长：双方均按左端采样保持到下一采样；缺读与超过 `seg_gap_s` 的间隔不外推；末拍无额外时长。首尾截断只计窗口内时长，边界单列；左右换向但未进死区仍为同一持杆段。
- 人工记录通过会话与来源元数据匹配，不接纳无元数据记录；输入指纹包含手柄与元数据文件。双方覆盖各自录制窗口，并非精确裁成同一观察窗口。
- 适用范围：只有「程序实际驾驶段」与「人工真实手柄输入」可比；
  人工局 trace 里的 `steer_x` 是未下发的反事实命令，单列不参与比较。

## 未定项

| 项 | 现状 |
|---|---|
| 证据有效 | 原实现无身份分支用 `not scene.stale` 测走廊状态，不能测对象证据；有身份分支还复用了选择资格标记。混合通过率作废；新口径需绑定对象种类 × 证据来源 × 用途，并允许「无法判定」 |
| 动作可行 | 原实现只测到站时间存在且为正，且含恒真条件；改名「时间信息可用」，不含可达性 |
| 几何阈值 | 只做分量对账，异常判定阈值待标定；不以 1 m 或 0.04 道作硬门 |
| 路心补偿成因 | 闭合误差见复算报告；成因（道路剖面 / 查询纵深 / 采样点限拍与超时直通）与下游影响未定，未判为生产故障或正常行为 |

## 对账规则

1. 只比较同一口径版本、参数、实现指纹与输入指纹的两次结果；不一致时报「不可直接比较」。
2. 不从方案正文或旧摘要抽取数字作为期望值；期望值只能来自同口径报告。
3. 报告必须带输入指纹、计算实现指纹与完整参数表；用 `--compare` 对已保存 JSON 复算，失败返回非零状态。

## 复算入口

从仓库根运行，原始记录默认通过本机运行目录定位；换机需提供报告所列指纹对应的原始记录，文件名相同不算同一输入。

```powershell
.venv/Scripts/python.exe maaracing_master/plugins/_archive/speedrush/experiments/speedrush_agility/recompute_report.py --trace "$env:APPDATA/MaaRacingMaster/logs/20261115_224956/trace/speedrush.jsonl" --pads-dir "$env:APPDATA/MaaRacingMaster/debug/speedrush"
```

同口径对账在上述命令后加 `--compare maaracing_master/plugins/_archive/speedrush/experiments/speedrush_agility/RECOMPUTE_REPORT.json`。手算边界检查运行 `test_metrics.py`；它只在实验区使用，不作为生产测试依赖。

## 旧入口

`probe_target_truth.py`、`probe_target_calibrate.py`、`verify_recomputed_stats.py`、
`probe_route_intent.py` 属旧口径（分母混入前值保持、单位换算与固定 0.05 s 时间基），
从未入库，已删除、不可恢复；其口径缺陷见本文件「未定项」与 `docs/plan/` 的腐化治理清单。
结论以本目录 `RECOMPUTE_REPORT.md` 为准。
