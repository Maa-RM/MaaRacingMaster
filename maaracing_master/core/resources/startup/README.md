# 启动链资源（startup）

「启动游戏」步骤专用的导航链。**不属于模块共用资源**：不放在
`core/resources/pipeline/`（那个目录会被所有模块的导航图自动并入），由
`LaunchGameStep` 经 `StepSession.graph()` 显式加载。决策与边界见
[ADR-0018](../../../../docs/adr/0018-criteria-core-启动步骤的完成判据与自有资源.md)。

## 文件

| 路径 | 说明 |
|---|---|
| `pipeline.json` | 状态机真源。节点前缀 `startup.`，入口 `startup.boot`，终点 `startup.done` |
| `image/startup_*.png` | 模板图，统一 `startup_` 前缀 |

## 模板图规则

- **720p 客户区裁剪**，与识别时的帧同源同尺寸；窗口截图先换算客户区。
- **ASCII 小写下划线**命名（cv2 中文路径历史坑），统一 `startup_` 前缀。
- 一个模板只装"一年后还长这样"的像素：角标、倒计时、数量、限时横幅留在模板外。
- 搜索区（节点里的 `rect`，归一化 0..1）为模板框外扩 10px；边长压到 ≤160px
  （实测 120×120 的搜索区约 1.6ms，600×400 约 73ms，汇聚节点 600ms 一轮扛不住大 ROI）。
- **大厅锚点阈值 0.90**：实测干净大厅帧 0.989/0.994，弹窗叠上来时最高 0.826。
  这是「已知覆盖层已清」的判据来源，不是靠画面变暗——`TM_CCOEFF_NORMED` 对亮度
  归一化，压暗后分数仍是 1.000，只有模糊才会掉分。

## 现状素材来源

大厅两个锚点来自 1280×720 真机截图；登录页与弹窗模板来自 2026-11-05 的启动录像
（1280×720，有压缩）。**录像素材待真机重拍替换**：换图时只改 `image/` 下的文件并
重跑真源测试，节点与矩形通常不用动。

## 未知页面兜底（2026-11-12）

枚举式候选表追不上版本更新：赛季切换一次冒出七个弹窗（维护公告、段位结算、赛季奖励、
分数继承、赛季速览、月卡、新车排位分），既有模板全部落空，进大厅耗到时限才放弃。
因此候选表末尾加了两条兜底，分工按「有没有字」划：

| 节点 | 判据 | 覆盖 |
|---|---|---|
| `startup.popup.close_x` | 全局模板（两张皮肤） | 无字控件（右上角关闭叉）。文字识别认不出图形，这类只能靠图 |
| `startup.advance` | 文字块 + 白名单 | 有字按钮（继续 / 进入 / 领取 / 确定 / 点击屏幕继续）。**位置未知**也要能点，所以开文本检测拿框 |

**关闭叉与返回箭头是全局模板**，图住在 `../image/`（见那里 README 的启用判据），启动链与
模块图按文件名直接引用，不各存一份。返回箭头（`common_back.png`）**暂未接进候选表**：
它的源帧压着旧版调试字幕，自匹配只有 0.739，而比赛页左上角图标误命中 0.737——两者压不开，
接上去会在比赛页点掉地图入口。等下一轮干净帧重裁后再接。

`startup.advance` 的实现与参数说明住 `maaracing_master/core/advance.py`；它只在
「已知弹窗、登录页、大厅确认全部不匹配」时才轮到，正常启动不付它的代价。代价是
每次约 1 秒（整帧文本检测，参数与实测见 `core/ocr.py` 的 `BLOCK_DET_*`），换来的是
新弹窗不再需要裁图标定。

**误点防护（三条，缺一条就不许上线）**：搜索区只在下半屏（顶部 HUD 有「领取/任务」
字样，不能成为候选）；文案白名单 + 长度上限（长段落即使含「继续」也不点）；黑名单
（购买/消耗/钻石/点券/取消/分享…）命中即淘汰。规则的单测在
`tests/test_core_advance.py`——那里红了才说明防护还在。

新增弹窗的优先路径仍然是模板：文字兜底是「不认识也能过」，不是「不用认识」。

## 校验

```bash
python tools/pipeline/truth.py
pytest tests/test_startup_truth.py
```

`truth` 把本目录纳入发现范围与命名空间检查：本目录节点名不得占用模块命名
空间，也不得引用 `<module>.` 节点。
