# 全局模板图目录（G1 归属可分 · §7.3 F9）

这里的图是 **`NavGraph` 构造时就挂进模板搜索路径的第一个目录**，所有图（模块图与启动链）
都能按文件名直接引用，不需要各自复制一份。

放什么：**跨页、跨模块长一个样的通用控件**。放进来之前先答一句「第二个使用者是谁」——
只有一个使用者的模板留在自己的资源目录里（启动链 → `../startup/image/`，插件 →
`plugins/<id>/resources/image/`），过早搬上来只是把私有件混进公共层。

| 模板 | 用途 | 来源 |
|---|---|---|
| `common_close_dark.png` | 深色弹窗右上角的白色关闭叉 | 赛季速览弹窗（2026-11-12） |
| `common_close_light.png` | 白色弹窗右上角的深色关闭叉 | 好友邀请弹窗（2026-11-12） |
| `common_back.png` | 左上角返回箭头（风格化 D 形） | 赛季维护公告页（2026-11-12） |

## 规则

- **720p 客户区裁剪**，与识别时的帧同源同尺寸；窗口截图先换算客户区（x=1 / y=38）。
- **只裁控件本身**，不带整屏背景、不带页面文字——背景一换就失效，这正是「通用」的前提。
- 命名统一 `common_` 前缀，避免与 `startup_*` / 插件模板混淆。
- **识别矩形（`rect`）不在这里**：搜索区随页面布局走（右上角还是弹窗内右上），是各图
  自己的知识，写在各自节点的 `recognition.custom_recognition_param.rect` 里。
